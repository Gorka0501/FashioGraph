# User Guide - Managing Items

Uploading, organizing, and managing individual clothing items.

## About Items

An **item** is a single piece of clothing in your wardrobe. Each item has:
- 📸 **Photo** - Picture of the clothing
- 📝 **Details** - Name, category, color, size
- 🏷️ **Tags** - Category classification
- 🧮 **Embeddings** - Mathematical representation for compatibility

### Supported Item Types

- **Tops**: Shirts, blouses, sweaters, hoodies
- **Bottoms**: Pants, shorts, skirts, jeans
- **Dresses**: All dress styles
- **Outerwear**: Jackets, coats, blazers
- **Footwear**: Shoes, boots, sneakers, heels
- **Accessories**: Belts, scarves, hats, bags

## Uploading Items

### Preparation

Before uploading, prepare your items:

1. **Take Photos**
   - Good lighting (natural light best)
   - Clear background (plain wall)
   - Item clearly visible
   - Multiple angles if possible

2. **Quality Check**
   - File size: Under 5MB
   - Format: JPG, PNG, or WebP
   - Dimensions: 800x800px or larger
   - Not blurry or dark

3. **Organize Files**
   - Save with descriptive names
   - Group by category (optional)
   - Create backup (optional)

### Single Item Upload

**Step 1: Open Wardrobe**
1. Click "Wardrobe" in navigation
2. Select desired wardrobe
3. Click "Add Item" or "+" button

**Step 2: Upload Image**
1. Click image upload area
2. Select photo from computer
3. Or drag-drop image into upload area
4. Image preview appears

**Step 3: Enter Details**
1. **Item Name** (required)
   - Example: "Blue Cotton T-Shirt"
   - Be specific and descriptive

2. **Category** (optional, auto-detected)
   - Shirts, Pants, Dresses, Shoes, etc.
   - Verify auto-detection accuracy
   - Correct if needed

3. **Color** (optional, auto-detected)
   - Select or type color
   - Multi-color items: list primary color

4. **Brand** (optional)
   - Example: "Nike", "Zara"
   - Helps with organization

5. **Size** (optional)
   - Standard sizes: XS, S, M, L, XL
   - Or numeric: 8, 10, 12
   - Or European: 36, 38, 40

6. **Notes** (optional)
   - Style tips
   - Care instructions
   - Where to wear
   - Price paid

**Step 4: Upload**
1. Click "Upload" button
2. Wait for processing (usually 2-5 seconds)
3. Confirmation message appears
4. Item added to wardrobe

### Batch Upload (Multiple Items)

**For uploading many items at once:**

1. Click "Bulk Upload" button
2. Select multiple images:
   - **Windows/Linux**: Ctrl+Click each image
   - **Mac**: Cmd+Click each image
   - Or Ctrl+A to select all in folder
3. Click "Open" or "Upload"
4. Processing begins

**During Batch Processing:**
- System uploads all images
- Auto-detects categories
- Shows progress bar
- Generates embeddings
- Notifies when complete

**Note:** May take longer for many items (1-2 minutes for 20+ items)

## Editing Items

### Update Item Information

1. **Open Item**
   - Click item in wardrobe
   - Or right-click → Edit

2. **Edit Mode**
   - Click "Edit" button
   - Fields become editable

3. **Modify Details**
   - **Name**: Change descriptive name
   - **Category**: Correct if mis-classified
   - **Color**: Update color info
   - **Size**: Add or change size
   - **Brand**: Add brand info
   - **Notes**: Add personal notes

4. **Save**
   - Click "Save" button
   - Changes applied immediately

### Change Item Photo

**Replace Photo:**
1. Open item
2. Click on image
3. Select "Change Photo"
4. Choose new image
5. Confirm

**Add Additional Photos:**
1. Open item
2. Click "Add Photo"
3. Select image
4. Multiple angles saved

## Categorizing Items

### Categories and Subcategories

#### Tops
- **Casual**: T-shirts, casual shirts
- **Formal**: Dress shirts, blouses
- **Layering**: Cardigans, jackets
- **Activewear**: Sports tops

#### Bottoms
- **Casual**: Jeans, casual pants
- **Formal**: Dress pants, trousers
- **Skirts**: All skirt styles
- **Shorts**: Summer/athletic shorts

#### Dresses
- **Casual**: Everyday dresses
- **Formal**: Evening dresses
- **Work**: Professional dresses
- **Casual**: Sundresses, maxi

#### Outerwear
- **Casual**: Hoodies, windbreakers
- **Formal**: Blazers, suit jackets
- **Seasonal**: Coats, heavy jackets
- **Lightweight**: Light layers

#### Footwear
- **Casual**: Sneakers, flats
- **Formal**: Heels, dress shoes
- **Activewear**: Running shoes
- **Seasonal**: Boots, sandals

#### Accessories
- **Jewelry**: Rings, necklaces, bracelets
- **Bags**: Purses, backpacks, totes
- **Hats**: Caps, beanies, hats
- **Other**: Scarves, belts, ties

### Auto-Categorization

**How it works:**
1. Upload item
2. System analyzes photo
3. Detects clothing type
4. Suggests category
5. You can accept or correct

**High Accuracy For:**
✅ Clear clothing items  
✅ Standard designs  
✅ Good lighting  
✅ Item fills photo  

**May Need Correction:**
⚠️ Multiple items in photo  
⚠️ Unclear/ambiguous items  
⚠️ Custom or unusual clothing  
⚠️ Poor lighting  

**Correcting Category:**
1. Click "Edit"
2. Select correct category
3. Save
4. System learns from corrections

## Color Management

### Color Detection

The system can identify:
- **Primary colors**: Red, Blue, Yellow, etc.
- **Neutrals**: Black, White, Gray, Beige, Brown
- **Multi-color**: Shows dominant color
- **Patterns**: Stripes, checks, florals

### Setting Colors Manually

1. Open item
2. Click "Edit"
3. Select from color palette or enter custom color
4. Save

### Color Filtering

When generating outfits:
- System considers colors
- Suggests compatible combinations
- Learns from your preferences

### Color Psychology Tips

**Warm Colors** (Red, Orange, Yellow):
- Energetic, cheerful
- Good for casual/social

**Cool Colors** (Blue, Green, Purple):
- Calming, professional
- Good for work/meetings

**Neutrals** (Black, White, Gray):
- Versatile, go with everything
- Good foundation for outfits

## Removing Items

### Delete Single Item

1. Open item
2. Click "Delete" or trash icon 🗑️
3. Confirm deletion
4. Item removed immediately

### Delete Multiple Items

1. **Select Items**
   - Checkbox next to each item
   - Or Ctrl+Click items

2. **Bulk Delete**
   - Click "Delete Selected"
   - Confirm
   - All selected removed

⚠️ **Important:** Deletion is permanent. Items won't appear in future outfits.

## Photo Tips and Best Practices

### Photography Checklist

✅ **Lighting**
- Natural light (window or outdoors)
- No harsh shadows
- Item well-lit
- Consistent brightness

✅ **Background**
- Plain wall or backdrop
- No clutter
- Contrasting color helps
- Professional appearance

✅ **Item Presentation**
- Item is focus
- Entire item visible
- Lies flat or on hanger
- Shows color and texture

✅ **Quality**
- In focus and sharp
- Right-side up
- Good angle
- Shows details

### Example Photos

**Good Photos:**
- Item on plain white background
- Natural daylight
- Item centered and full
- Colors accurate
- Professional appearance

**Poor Photos:**
- Item on messy closet background
- Dark or uneven lighting
- Item partially cut off
- Colors look wrong
- Blurry or dark

### Editing Photos

Before uploading, consider:
- Cropping to item
- Adjusting brightness
- Removing background (optional)
- Resizing to standard size
- Converting to JPG for smaller size

## Item Embeddings (Technical)

### What are Embeddings?

Mathematical representation of item for:
- Outfit compatibility calculations
- Similarity matching
- Recommendation generation

### Auto-Generation

- Created automatically on upload
- Regenerated when category changes
- No action needed from you
- Used internally by system

## Troubleshooting

### Upload Fails

**Check:**
1. File is image (jpg, png, webp)
2. File is under 5MB
3. File not corrupted
4. Format supported

**Solutions:**
1. Compress image using image tool
2. Convert to JPG format
3. Try different image
4. Check internet connection

### Category Misclassified

**Solution:**
1. Open item
2. Click "Edit"
3. Select correct category
4. Save
5. System learns for future

### Photo Looks Different

**Possible Causes:**
- Monitor color calibration
- Lighting affects appearance
- Camera white balance
- Compression quality

**Solution:** Upload is accurate representation - lighting may differ
