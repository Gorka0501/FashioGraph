# User Guide - Wardrobe Management

Organizing and managing your clothing collection.

## What is a Wardrobe?

A **wardrobe** is your digital clothing collection. Think of it as a virtual closet where you:
- Store all your clothing items (photos)
- Organize by category, color, season
- Generate outfit combinations
- Track outfit history

### Key Features

✅ Multiple wardrobes possible (optional)  
✅ Organize by occasion, season, or style  
✅ Automatic categorization  
✅ Statistics and insights  
✅ Outfit generation from items  

---

## Creating Your First Wardrobe

### Step 1: Open Wardrobe Section

**Web/Desktop:**
1. Click "Wardrobe" in navigation menu
2. Or click "My Wardrobe" on dashboard

**Mobile:**
1. Tap "Wardrobe" tab
2. Or tap "Add Wardrobe"

### Step 2: Create New Wardrobe

1. Click "Create New Wardrobe" or "+" button
2. Enter wardrobe name:
   - Examples: "Summer 2024", "Work Clothes", "Casual"
3. Optional: Add description
   - Example: "Light fabrics for warm weather"
4. Click "Create"

### Step 3: Confirmation

You'll see:
- ✅ Wardrobe created
- Empty wardrobe (ready for items)
- "Add Items" button

## Managing Multiple Wardrobes

### When to Create Multiple Wardrobes

| Wardrobe | Best For | Example |
|----------|----------|---------|
| **Seasonal** | Organize by weather | Summer, Winter, Spring |
| **Occasion** | Different event types | Work, Casual, Evening |
| **Style** | Different aesthetics | Minimalist, Colorful, Classic |
| **Activity** | Different purposes | Gym, Travel, Beach |

### Switching Between Wardrobes

**Web/Desktop:**
1. Click "All Wardrobes" or dropdown
2. Select desired wardrobe
3. Items and outfits switch to that wardrobe

**Mobile:**
1. Tap wardrobe selector
2. Choose from list
3. View that wardrobe's items

### Editing Wardrobe Info

1. Open wardrobe
2. Click settings icon ⚙️
3. Edit name and description
4. Save changes

### Deleting a Wardrobe

1. Go to wardrobe
2. Click settings ⚙️
3. Select "Delete Wardrobe"
4. Confirm deletion
5. ⚠️ All items in wardrobe deleted too

## Adding Items to Wardrobe

### Upload Single Item

1. Open wardrobe
2. Click "Add Item" or "+" button
3. Select image from computer
4. Enter item details:
   - **Name**: Descriptive name (e.g., "Blue T-shirt")
   - **Category**: Auto-detected or select
   - **Color**: Specified or auto-detected
   - **Brand**: Optional
   - **Size**: Optional
5. Click "Upload"
6. Item added to wardrobe

### Batch Upload (Multiple Items)

1. Click "Bulk Upload" or "Upload Multiple"
2. Select multiple images (Ctrl+Click or Cmd+Click)
3. Click "Upload All"
4. Items processed and added

### Auto-Categorization

The system automatically:
- 📷 Detects clothing type (shirt, pants, etc.)
- 🎨 Identifies color
- 🏷️ Generates embeddings for compatibility

### Manual Adjustments

After upload, you can:
1. Edit item details
2. Change category if misclassified
3. Correct color
4. Add notes

## Editing Items

### Change Item Details

1. Click item to open
2. Click "Edit" button
3. Modify:
   - Name
   - Category
   - Color
   - Size
   - Brand
   - Notes
4. Save changes

### Change Item Photo

1. Open item
2. Click on image
3. Select new photo
4. Confirm
5. Photo updated

### Adding Notes

1. Open item
2. Scroll to "Notes" section
3. Add personal information:
   - Where purchased
   - Care instructions
   - Styling ideas
   - Memories
4. Save

### Marking Favorites

1. Open item
2. Click star icon ⭐
3. Item marked as favorite
4. Quick filter to see favorites

## Removing Items

### Delete Single Item

1. Open item
2. Click "Delete" or trash icon 🗑️
3. Confirm deletion
4. Item removed from wardrobe

⚠️ **Note:** This only removes from digital wardrobe, not your actual closet!

### Delete Multiple Items

1. Select multiple items (checkbox or Shift+Click)
2. Click "Delete Selected"
3. Confirm
4. All selected items removed

## Best Practices

### Photography Tips

✅ **Good Lighting**
- Use natural light
- Clear shadows
- Consistent brightness

✅ **Clear Subject**
- Item is focus
- No clutter in background
- Item lies flat or on hanger

✅ **Proper Framing**
- Entire item visible
- All colors visible
- Show texture/details

### Metadata Tips

✅ **Descriptive Names**
- Not: "Shirt"
- But: "Blue Button-Up Oxford"

✅ **Accurate Categories**
- Select closest category
- System learns from corrections

✅ **Complete Info**
- Include size
- Note brand
- Add any special features

### Maintenance

✅ **Regular Updates**
- Add new purchases
- Remove worn-out items
- Update descriptions

✅ **Remove Duplicates**
- Check for multiple uploads of same item
- Keep one version

✅ **Archive Old Items**
- Keep rarely worn for seasonal rotation
- Or delete if really won't wear

## Troubleshooting

### Items Not Showing

**Check:**
1. Selected correct wardrobe
2. Items were actually uploaded
3. Refresh page/app
4. Check upload wasn't cancelled

**Try:**
1. Reload application
2. Logout and login
3. Check browser console for errors

---

### Incorrect Categorization

**Solution:**
1. Open item
2. Click "Edit"
3. Select correct category
4. Save

**Note:** System learns from corrections over time.

---

### Unable to Upload

**Check:**
1. File is image (jpg, png, webp)
2. File is less than 5MB
3. Image file not corrupted
4. Internet connection active

**Try:**
1. Compress image
2. Convert to JPG format
3. Try different image
4. Restart application
