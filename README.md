# APP

Fashion-focused full-stack app with a Python backend, ML pipeline, and a lightweight frontend.

## What’s inside
- Backend API and services in app/
- Frontend client in frontend/
- ML training/evaluation assets in ml_pipeline/
- Shared models in models/

## Requirements
- Python 3.10+ recommended
- Windows, macOS, or Linux

## Quick start
1. Create and activate a virtual environment.
2. Install dependencies for the backend and frontend as needed.
3. Start the API:
   - python start.py
4. Start the web app (if applicable):
   - python start_web.py

## Testing
Run the test suite:
- pytest

## Documentation
Project docs live in app/docs/.

## Repository structure
- app/ — backend API, routes, schemas, and services
- frontend/ — UI and client helpers
- ml_pipeline/ — datasets, notebooks, experiments
- models/ — model artifacts and loaders
